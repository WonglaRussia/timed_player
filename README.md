# Timed Player

Плеер, который проигрывает видео, аудио и картинки **по расписанию, без участия человека**:
в заданное время, с заданного места в файле, с заданной громкостью.

Сейчас: Windows. Код рассчитан и на Linux; Android — позже (нужен вывод видео внутри приложения).

## Как это устроено

Расписание — это шкала времени, как на исходном рисунке: у каждого элемента есть

| Поле | Смысл |
|---|---|
| Старт | когда начать, от начала расписания (или по часам) |
| С позиции | с какого места файла играть (по умолчанию — с начала) |
| Длительность | сколько играть; пусто — до конца файла (картинка — 10 с) |
| Громкость | 0–100 % |
| Нарастание / затухание | плавное изменение громкости в начале и в конце, секунды |

Начало расписания задаётся одним из способов:

- **Кнопкой** — «Старт» запускает сейчас; если на шкале стоит курсор, то так, будто уже прошло
  столько времени (удобно для прогона с середины).
- **Один раз** — в заданные дату и время.
- **По дням** — в заданное время в выбранные дни недели.

«Время по часам» в таблице и на шкале показывает, во сколько по часам сыграет каждый элемент;
в диалоге элемента время старта можно вводить и так.

### Правила проигрывания

- **Экран** (видео и картинки) — одно за раз. Элемент, начавшийся позже, перекрывает
  предыдущий; когда он закончится, предыдущий продолжится с того места, где он был бы
  по времени. Так можно поверх длинного фона вставлять короткие ролики.
- **Звук** (аудио) играет параллельно с видео и с другим аудио.
- **Опоздание**: если программу или расписание запустили позже, всё начинается так, как будто
  играло с самого начала, — ролик стартует с того места, где он должен быть сейчас.
- Видео выводится в отдельном окне на выбранном мониторе, на весь экран. Окно открывается
  за 2 секунды до первого ролика или картинки и закрывается после последнего; между ними
  экран чёрный или с заставкой. Esc в окне вывода выходит из полноэкранного режима, F — вернуть.
- Если видео разойдётся с часами больше чем на 1,5 с (подтормозил диск или декодер),
  позиция поправляется.

### Без присмотра

- Пока расписание включено, компьютер и экран не уходят в сон.
- Закрытие окна при включённом расписании прячет программу в трей — проигрывание продолжается.
  Выход — из меню значка в трее.
- Если программа закрылась аварийно (сбой, отключение питания), при следующем запуске она
  продолжит включённое расписание с нужного места.
- Журнал: что, когда и с каким опозданием сыграло, ошибки (файл не найден и т. п.).
  Хранится по дням в `%APPDATA%\app.local\timed_player\journal\ГГГГ-ММ-ДД.log`,
  последние строки видны в окне программы.

## Файлы расписаний

Расписание сохраняется в файл `*.tplay` (JSON). Медиафайлы, лежащие в той же папке или
во вложенных, записываются относительными путями — папку можно перенести на другой компьютер
целиком.

## Командная строка

```
timed_player.exe [файл.tplay] [--start | --arm] [--exit-when-done]
```

- `--start` — сразу запустить расписание (как кнопка «Старт»);
- `--arm` — включить расписание по времени;
- `--exit-when-done` — закрыть программу, когда расписание отыграет.

Это позволяет, например, запускать программу из Планировщика заданий Windows.

## Сборка

Нужны Flutter (stable), Visual Studio 2022 с компонентами «Разработка классических
приложений на C++» (MSVC, Windows SDK, CMake) и включённый в Windows режим разработчика
(Flutter использует символические ссылки для плагинов).

```
flutter test
flutter build windows --release
```

Готовая программа — папка `build\windows\x64\runner\Release` целиком (exe рядом с DLL,
включая `libmpv-2.dll`).

## Устройство кода

- `lib/core/` — модель расписания, расчёт времени запуска, правила «что играет сейчас»
  (чистый Dart, покрыто тестами).
- `lib/playback/` — `Runner` сверяет желаемое состояние с плеерами каждые 40 мс;
  `MpvBackend` — воспроизведение на libmpv (media_kit).
- `lib/services/` — журнал, настройки, запрет сна, окно и трей.
- `lib/ui/` — редактор: шкала, таблица, диалоги.
